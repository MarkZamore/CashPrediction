# CashPrediction

Учёт личных финансов с прогнозом будущего баланса. Вы вводите текущий бюджет, даты поступлений и трат, разовые операции и корректировки конкретных дат. Программа показывает, сколько денег будет через месяц, год или любой другой срок, в виде таблицы событий и графика.

## Скачать

[Скачать последнюю версию CashPrediction-portable.zip](https://github.com/MarkZamore/CashPrediction/releases/latest/download/CashPrediction-portable.zip)

1. Распакуйте архив в любую папку, например на рабочий стол или флешку.
2. Запустите `CashPrediction.exe`. Установка и Java не нужны.
3. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае». Так Windows реагирует на любую программу без платной цифровой подписи.

Все данные хранятся в папке `CashMemory` рядом с программой. Чтобы перенести программу вместе с планами, скопируйте всю папку.

Приложение существует в трёх равноценных вариантах над одним ядром:

| Клиент | Технология | Файл запуска |
|---|---|---|
| Настольный | JavaFX | `CashPrediction.exe` |
| Настольный | Swing | `CashPrediction-Swing.exe` |
| Web, тонкий клиент | встроенный HTTP-сервер JDK, HTML и JavaScript | `CashPrediction-Web.exe` (открывает браузер) |

## Возможности

- **План**: начальный баланс на дату, горизонт прогноза, подушка безопасности, цель накопления.
- **Регулярные операции**: ежемесячно в заданный день (31 означает последний день месяца), раз в N месяцев, еженедельно, каждые N дней, ежегодно. Можно задать даты начала и окончания и сдвиг с выходных на пятницу или понедельник.
- **Разовые операции** на конкретную дату.
- **Корректировки** одного события из плана: пропустить, изменить сумму, перенести, заменить.
- **Таблица**: вертикальный список событий с нарастающим балансом. Регулярная операция «5-го числа +80 000» даёт строку на 5-е число каждого месяца до конца периода. Минусовой баланс и баланс ниже подушки подсвечиваются.
- **График** баланса на временной шкале с линиями нуля, подушки и цели.
- **Сводка**: баланс через 1, 3, 6, 12 месяцев, минимум, первая дата ухода в минус, дата достижения цели.
- **Калькулятор цели**: когда накопится нужная сумма и сколько откладывать дополнительно, чтобы успеть к дате.
- **«Что если»**: доходы или расходы ±10 %, дополнительная экономия в месяц, с применением к плану одной командой.
- **Сверка баланса** с реальным остатком и **актуализация** плана на сегодня.
- Отмена и повтор, фильтр, проверка плана, экспорт в CSV, горячие клавиши.

## Данные: папка CashMemory

Программа ничего не устанавливает и не создаёт файлов вне папки `CashMemory`, которая появляется рядом с exe при первом запуске.

| Файл | Содержимое |
|---|---|
| `<имя плана>.md` | план в человекочитаемом Markdown |
| `settings.md` | последний план, вид, период, фильтры |
| `session-fx.xml`, `session-swing.xml` | снимок сессии настольных клиентов для восстановления после сбоя |
| `web-session.md`, `web-session.plan.md` | состояние сессии web-сервера |

Файл плана можно открыть и поправить в Блокноте. Программа читает ручные правки терпимо: порядок колонок, лишние пробелы, даты `05.10.2026` или `2026-10-05`. Нераспознанный текст не теряется, а строки с ошибками попадают в заметку плана с номером строки. Фрагмент файла:

```markdown
# План: Семейный бюджет 2026

## Параметры

- Формат: CashPrediction 1
- Валюта: ₽
- Начало: 2026-09-01
- Горизонт: 12 месяцев
- Начальный баланс: 150 000,00

## Регулярные операции

| ID | Название | Тип    | Сумма     | Категория | Повтор       | С | По | Выходные | Активна | Заметка |
|----|----------|--------|-----------|-----------|--------------|---|----|----------|---------|---------|
| r1 | Зарплата | доход  | 80 000,00 | Зарплата  | ежемесячно 5 |   |    | раньше   | да      |         |
| r2 | Аренда   | расход | 45 000,00 | Жильё     | ежемесячно 1 |   |    | нет      | да      |         |
```

Полное описание формата: [docs/FORMAT.md](docs/FORMAT.md), а также «Справка → Формат файла .md» в программе.

## Восстановление после аварийного закрытия

Во время работы программа записывает снимок сессии: открытые окна, введённые в них значения, несохранённые изменения плана, вид и выделение. Снимок пишется одновременно в два независимых места:

| Хранилище | Где смотреть |
|---|---|
| Реестр Windows | прежний интерфейс: `HKEY_CURRENT_USER\Software\JavaSoft\Prefs\ru\cashprediction\session\fx` (и `\swing`); интерфейс ядра (`--ui core`): отдельный узел каждой портативной копии `…\session\fx-<8 символов>` (и `swing-…`), а путь её папки CashMemory записан рядом в значении `cashmemory.path` |
| XML-файл | `CashMemory\session-fx.xml` (и `session-swing.xml`) |

Если прошлый запуск завершился аварийно, при старте появляется диалог с выбором: восстановить из реестра, из XML-файла или не восстанавливать. Web-клиент хранит состояние на сервере. Перезагрузка страницы возвращает те же открытые окна и значения. После аварийного падения сервера страница предлагает восстановить сеанс.

Как показать восстановление:

1. Откройте, например, «Правка → Добавить расход…» и введите данные, не нажимая «Сохранить».
2. Выберите «Восстановление → Симулировать сбой → Аварийное завершение процесса».
3. Запустите программу снова и выберите «Из реестра Windows» или «Из XML-файла».

Меню «Восстановление» также позволяет выбрать хранилище по умолчанию, сделать снимок вручную, посмотреть последний снимок и очистить снимки.

## Сборка

Подробно: [docs/BUILD.md](docs/BUILD.md).

```
mvn -B install                         сборка и тесты
mvn -B -Pdist -DskipTests package      портативная папка с тремя exe и zip-архив
```

Готовая папка: `dist/target/dist/CashPrediction`. Её можно скопировать на любой Windows 10/11 x64 без установленной Java.

## Структура проекта

| Модуль | Назначение |
|---|---|
| `core` | модель, движок прогноза, файлы CashMemory, снимки сессии и три хранилища; без UI, покрыт тестами |
| `ui-fx` | клиент JavaFX |
| `ui-swing` | клиент Swing |
| `web` | web-сервер и браузерный клиент |
| `dist` | jlink + jpackage |

## Комментарии в коде

- Javadoc на русском у каждого класса и каждого открытого метода.
- Внутри методов комментарии объясняют, почему сделано так, а не что делает строка.
- У каждого использования перечисленных JavaFX-классов и их аналогов стоит комментарий соответствия JavaFX → Swing → Web.
- Файлы CashMemory комментариев не содержат: в них только данные.

## Ограничения

- Поставка - портативная папка, а не один exe. GraalVM native-image не поддерживает Swing на Windows, а JavaFX там не собирается.
- Сдвиг с выходных учитывает субботу и воскресенье, праздники не учитываются.
- Web-сервер слушает только `127.0.0.1` и рассчитан на одного пользователя.
