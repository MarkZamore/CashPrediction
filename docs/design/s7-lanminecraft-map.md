## 6. Утверждённая Java/JDK адаптация и точки подключения

Tree-delta не является портом bsdiff. По protocol:41 JDK ZIP содержит patch.json и полные bytes добавленных/изменённых файлов; неизменившиеся берутся из установленного дерева, удалённые отсутствуют в target inventory. Сначала проверяются container size/hash, затем каждый target file и treeSha256. Read-only входит в identity; timestamps ZIP не входят. Дельты двух баз должны независимо давать тот же target, что full ZIP. Runtime не загружает app-image целиком в память. Источник target inventory один, общий для трёх клиентов.
