# Формат файла плана (.md)

Каждый план хранится в папке CashMemory отдельным текстовым файлом `<имя плана>.md`.
Файл можно открыть и исправить в Блокноте: программа прочитает его снова, а всё, чего она
не поняла, покажет в списке диагностики и не потеряет при сохранении.

## Общие правила

- Кодировка UTF-8 (с BOM или без), переводы строк любые.
- Регистр букв, лишние пробелы и различие «ё/е» не важны.
- Пустое значение: пустая ячейка, `-` или `—`.
- Даты: `ГГГГ-ММ-ДД` (так пишет программа) или `ДД.ММ.ГГГГ`.
- Суммы: `80 000,00`, `80000.5`; пробелы между разрядами любые. Знак у сумм операций не нужен —
  доход или расход задаёт колонка «Тип».
- Секции начинаются строкой `## Название`. Свои секции (например, `## Мои заметки`) можно добавлять:
  они сохранятся на том же месте.

## Структура

```
# План: Семейный бюджет 2026

## Параметры

- Формат: CashPrediction 1
- Валюта: ₽
- Начало: 2026-09-01
- Горизонт: 12 месяцев
- Начальный баланс: 150 000,00
- Подушка безопасности: 50 000,00
- Цель: 300 000,00
- Цель к дате: 2027-06-01
- Название цели: Отпуск

## Заметка

Любой текст.

## Регулярные операции

| ID | Название | Тип   | Сумма     | Категория | Повтор       | С          | По | Выходные | Активна | Заметка |
|----|----------|-------|-----------|-----------|--------------|------------|----|----------|---------|---------|
| r1 | Зарплата | доход | 80 000,00 | Зарплата  | ежемесячно 5 | 2026-09-01 |    | раньше   | да      |         |

## Разовые операции

| ID | Дата       | Название | Тип    | Сумма     | Категория | Заметка |
|----|------------|----------|--------|-----------|-----------|---------|
| t1 | 2027-01-10 | Ноутбук  | расход | 90 000,00 | Техника   |         |

## Корректировки

| Правило | Исходная дата | Действие | Новая сумма | Новая дата | Заметка       |
|---------|---------------|----------|-------------|------------|---------------|
| r1      | 2026-12-05    | изменить | 95 000,00   |            | годовой бонус |
```

## Параметры

| Ключ                 | Обязателен | Значение                                                  |
|----------------------|------------|-----------------------------------------------------------|
| Формат               | нет        | `CashPrediction 1`                                        |
| Валюта               | да         | обозначение: ₽, $, € …; по умолчанию ₽                    |
| Начало               | да         | дата, на которую известен начальный баланс; по умолчанию сегодня |
| Горизонт             | да         | `12 месяцев`, `6 мес`, `2 года`, `5 лет`, `до 2027-12-31`; по умолчанию 12 месяцев |
| Начальный баланс     | да         | сумма, может быть отрицательной; по умолчанию 0           |
| Подушка безопасности | нет        | сумма; баланс ниже неё подсвечивается                     |
| Цель                 | нет        | сумма накопления                                          |
| Цель к дате          | нет        | желаемая дата (только вместе с «Цель»)                    |
| Название цели        | нет        | текст (только вместе с «Цель»)                            |

## Таблицы

Колонки ищутся по названию: порядок любой, необязательные колонки можно не писать.
Символ `|` внутри ячейки записывается как `\|`.

**Регулярные операции.** Обязательные колонки: Тип, Сумма, Повтор.
Необязательные: ID (назначается сам), Название, Категория, С и По (границы действия правила),
Выходные (по умолчанию `нет`), Активна (по умолчанию `да`), Заметка.

**Разовые операции.** Обязательные колонки: Дата, Тип, Сумма. Необязательные: ID, Название, Категория, Заметка.

**Корректировки** одного события регулярной операции. Обязательные колонки: Правило (ID правила),
Исходная дата (дата события по правилу, до сдвига с выходных), Действие.
Необязательные: Новая сумма, Новая дата, Заметка.

## Значения

- **Тип:** `доход` или `расход` (также `+` / `-`).
- **Повтор:**
  - `ежемесячно 5` — каждый месяц 5-го числа; `ежемесячно 31` — в последний день месяца;
  - `каждые 2 месяца 10` (также `месяц`, `месяцев`, `мес`) — отсчёт от даты «С» или от начала плана;
  - `еженедельно сб` (дни: `пн`, `вт`, `ср`, `чт`, `пт`, `сб`, `вс` или полные названия);
  - `каждые 2 недели пт`;
  - `ежедневно`, `каждые 3 дня` (также `день`, `дней`);
  - `ежегодно 03-15` или `ежегодно 15.03`; 29 февраля в невисокосный год — 28 февраля.
- **Выходные:** `нет` — не сдвигать; `раньше` — субботу и воскресенье на пятницу; `позже` — на понедельник.
- **Активна:** `да` / `нет` (также `yes` / `no`, `true` / `false`, `1` / `0`).
- **Действие:** `изменить` (нужна «Новая сумма»), `перенести` (нужна «Новая дата»),
  `пропустить`, `заменить` (нужны обе).

## Если что-то не так

- Строка таблицы с ошибкой (например, буква «О» вместо нуля в сумме) не попадает в прогноз:
  она переносится в «Заметку» с пометкой `(не разобрано, строка N: …)`. Исправьте строку
  и верните её в таблицу.
- Повторяющийся или пустой ID заменяется новым.
- Строка заметки, начинающаяся с `#`, записывается как `\#`, чтобы не стать заголовком секции.
- Файл без заголовка `# План:` и без единой известной секции планом не считается и не открывается.
