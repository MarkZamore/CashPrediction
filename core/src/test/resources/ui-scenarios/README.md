# Сценарии S2

Все 18 файлов исполняются настоящим AppController через ModelUiDriver. UiGoldenTest проверяет ошибки каждой строки и пользовательские результаты до записи эталонов. Дампы остаются JSON схемы UiDump 1 с массивами; преобразование дерева для сравнения не является изменением wire-формата.

Дата прогноза - 13.09.2026. Тест задаёт фиксированные часы на 12:00, отдельную папку приложения и реестр в памяти. Все файлы приложения остаются внутри временного CashMemory.

Для s14 тестовый внешний участник дожидается `signal external-change` и меняет время модификации сохранённого файла в изолированном CashMemory. Сам сценарий проходит обычные вопросы о перезаписи, отмене и перечитывании.

Для s17 предыдущий настоящий контроллер открывает пример, сохраняет план, открывает параметры и вводит некорректный баланс. Периодический рекордер создаёт настоящий XML-снимок. Следующий контроллер показывает восстановление до главного окна; сценарий выбирает XML и проверяет сохранение некорректного ввода.

Для s18 подготовлен сохранённый план и удерживается отдельная вспомогательная JVM того же java.exe. Её pid и момент запуска записаны в маркер XML. CrashDetector должен подтвердить ALREADY_RUNNING. Вспомогательная JVM не запускает приложение и не обращается к реестру; тест завершает её и проверяет завершение процесса.

Обновление эталонов: `mvn -B -pl core -Dtest=UiGoldenTest -Dcashprediction.golden.update=true test`. Проверка всей области: `mvn -B -pl core -Dtest=SelfTestScriptTest,SelfTestRunnerTest,VirtualSchedulerTest,ModelUiDriverTest,UiGoldenTest test`. Команды выполняет ведущий последовательно, затем запускает полный `mvn -B install`.

Сценарии находятся в основном ресурсе `core/src/main/resources/ru/cashprediction/core/ui/scenarios` и входят в jar ядра, чтобы запускаться из портативных exe без тестового classpath. Сценарий s18 сейчас использует desktop-кнопку; web-harness должен выбрать локализованную кнопку «Продолжить». Для выбора XML в s17 подготовка обязана сохранить время снимка 12:00:00.

ModelUiDriver не рисует PNG и не делает снимки экрана. Команды `shot` и экспорт PNG требуют настоящего графического драйвера и не могут давать фиктивный успех. Геометрия областей не выдумывается; её сравнивают графические клиенты.

Дайджест таблицы: SHA-256 по всем видимым строкам в их порядке. Для каждой строки `cells` записываются UiJson в UTF-8; в хеш сначала поступает длина этой записи как четыре байта big-endian, затем сами байты. Это сохраняет различие между разделителями внутри ячеек и границами строк. В дамп выводятся первые 60 строк и выделенная строка, если она находится дальше.
