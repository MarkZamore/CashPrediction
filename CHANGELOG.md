# История версий

Номер версии равен числу коммитов в ветке `main`. Перед каждым коммитом в `main` сверху добавляется запись с заголовком «## номер» и ровно одной строкой «- …» простым русским языком о том, что изменилось для пользователя. Без записи для текущего номера CI не публикует релиз.

## 8
